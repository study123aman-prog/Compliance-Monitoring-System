## 1. Scenario

A trade-finance client submits **letters of credit for goods priced 300% above market value**. The **beneficiary is in a high-risk jurisdiction**. Internal communications show a **relationship manager (RM) overrode compliance screening flags twice**. Wire transfers are **routed through 5 intermediary banks**. And a **regulatory update 2 weeks ago added the beneficiary's country to an enhanced-due-diligence (EDD) list**. This is the capstone: **every agent contributes a distinct signal**, the Consensus Engine fuses them, multiple special triggers fire, and the outcome reaches the **board**.

## 4. Consensus — three-way Dempster–Shafer (pairwise, commutative)

Each agent weighted by authority in the domain of **its own** evidence; combine pairwise (order-independent):

```
m_TM(V) = 0.70 · 0.80 = 0.560     (AML)
m_CS(V) = 0.90 · 0.78 = 0.702     (record-keeping — the override record)
m_RU(V) = 0.75 · 0.85 = 0.638     (AML)

Step 1 — TM ⊕ CS:
  Belief = 0.560 + 0.702 − 0.560·0.702 = 1.262 − 0.39312 = 0.86888  ≈ 0.869

Step 2 — (TM⊕CS) ⊕ RU:
  Belief = 0.869 + 0.638 − 0.869·0.638 = 1.507 − 0.554422 = 0.952578 ≈ 0.95
```

Consensus confidence **0.95**, severity **CRITICAL**. Three independent, individually-moderate signals compound into near-certainty — the intended payoff of corroboration across agents and domains. (RG assembles the outputs; it casts no vote.)

## 5. Escalation — T4, then raised to Board by stacked triggers

Confidence 0.95 → band **T4**; CRITICAL severity floor → **T4**; `tier = max(T4, T4) = T4`. Then **multiple special triggers**, each of which may only **raise** the response, fire together:

- **Sanctions/AML** → immediate **transaction hold** + SAR track.
- **RM override (C7)** → parallel **conduct investigation** (an employee subverted a control).
- **SAR filing + high-value cross-border TBML** → **board-level reporting** hook above T4.

Net: **T4 + Board**. SLA ack 15 m / resolve 24 h (CRITICAL). The **SAR filing follows dual control** ([critical-filing-tree](../../docs/escalation/decision-trees/critical-filing-tree.md)) with the 24-hour SAR clock; no filing or hold release happens without human sign-off.

## 6. Report & audit

RG assembles the full package: **SAR draft**, **trade-finance review**, **RM conduct-investigation brief**, **sanctions/EDD screening record**, and the **board summary**. Every message, the three agent alerts, the consensus computation, the escalation, the transaction hold, and each report artifact are hash-chained and ECDSA-signed under `correlation_id = C20-TBML` — a single reconstructable case file spanning all four agents.
