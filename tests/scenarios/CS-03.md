## 1. Scenario

A financial advisor recommends **high-risk leveraged ETF products** to **12 retirement-account clients aged 68–82**, describing them as **"safe income generators."** None of the clients' investment policy statements (IPS) permit speculative instruments. This is a two-signal case: the **misrepresentation lives in the communications** (CS) and the **unsuitable positions live in the accounts** (TM).

## 2. Detection

**CS** flags the advisor's language: "safe income generators" applied to leveraged ETFs is a **material misrepresentation of risk**; the recipient cohort (retirement accounts, ages 68–82) raises materiality. CS calibrated confidence **0.70**, domain *communications*.

**TM** independently confirms the **positions actually exist** in the 12 accounts and that each **contradicts the client's IPS** (speculative instruments disallowed). TM calibrated confidence **0.62**, domain *trading*.

Neither signal alone is conclusive — a risky *recommendation* isn't a violation until acted upon, and a position alone might be client-directed. Together they corroborate a **suitability violation**, so the Orchestrator routes both to the Consensus Engine.

## 4. Consensus (worked)

Agreement/corroboration path → **Dempster-Shafer**, `mᵢ(V) = wᵢ(domain)·cᵢ`, `Belief(V) = m_CS(V) + m_TM(V) − m_CS(V)·m_TM(V)` (K = 0, no benign mass):

```
m_CS(V) = 0.95 · 0.70 = 0.665        (CS authoritative in communications)
m_TM(V) = 0.95 · 0.62 = 0.589        (TM authoritative in trading)
Belief(V) = 0.665 + 0.589 − 0.665·0.589
          = 1.254 − 0.3917 = 0.8623 ≈ 0.86
```

Consensus confidence **0.86**, severity **HIGH** (a clear suitability breach; individualized client harm assessment benefits from human review, so HIGH rather than CRITICAL).

## 5. Escalation

HIGH → severity floor **T3**; confidence 0.86 → band **T3**; no special trigger → **tier = max(T3, T3) = T3** (Compliance Manager). SLA ack 1 h / resolve 72 h. Recommended action: freeze further recommendations from FA-2207, review all 12 accounts for remediation/rescission, assess Reg BI care-obligation breach.

## 6. Report & audit

RG produces a suitability case report enumerating the 12 affected clients and the IPS conflict. Both agent ALERTs, the consensus RESPONSE, the escalation, and the report are hash-chained/signed under `correlation_id = C3-SUIT`.
