## 1. Scenario

Customer account data for **14,000 EU residents** is transferred to a server in a **non-adequate jurisdiction** during a routine system migration — **without safeguards, consent, or Standard Contractual Clauses (SCCs)**. Detection combines a **record-keeping / data-movement signal** (CS) with a **regulatory-applicability judgement** (RU) that GDPR Chapter V is engaged.

## 2. Detection

**CS** (which owns record-keeping/communications surveillance) detects the **bulk data movement** — 14,000 EU-resident records egressing to a non-adequate destination in the migration logs, with **no SCC/consent artifact** attached. CS confidence **0.68**, evaluated in its *record-keeping* domain (authority 0.90).

**RU** determines the transfer **engages GDPR Art 44–49** and that, post-**Schrems II**, absence of SCCs/adequacy makes it unlawful; it attaches the citation and the **72-hour breach-notification clock**. RU confidence **0.72**, *regulatory* domain (authority 0.95).

## 4. Consensus (worked)

Each agent is weighted by authority in the domain of **its own evidence** (CS = record-keeping, RU = regulatory); corroboration → Dempster-Shafer:

```
m_CS(V) = 0.90 · 0.68 = 0.612       (CS authoritative in record-keeping)
m_RU(V) = 0.95 · 0.72 = 0.684       (RU authoritative in regulatory)
Belief(V) = 0.612 + 0.684 − 0.612·0.684
          = 1.296 − 0.4186 = 0.8774 ≈ 0.88
```

Consensus confidence **0.88**, severity **HIGH** (a serious, well-evidenced GDPR breach; remediation is largely procedural, so HIGH not CRITICAL).

## 5. Escalation

HIGH → severity floor **T3**; confidence 0.88 → band **T3**; **tier = max(T3, T3) = T3** (Compliance Manager). SLA ack 1 h / resolve 72 h — the 72-hour resolve SLA is aligned to the GDPR breach-notification deadline, and the **DPO is notified** as a mandatory recipient. Recommended action: halt/reverse the transfer, assess Art 33 regulator notification within 72 h.

## 6. Report & audit

RG produces a breach-assessment report and a regulator-notification draft; the 72-hour clock is tracked to prevent silent lapse. All steps hash-chained/signed under `correlation_id = C11-GDPR`.
