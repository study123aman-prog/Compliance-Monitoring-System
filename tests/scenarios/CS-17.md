## 1. Scenario

An **84-year-old** client's account shows **47 trades in a single month** (baseline: ~2/month over five years). A **new power of attorney (POA) was filed 6 weeks ago**, the account has **declined 22%**, and communications show the **POA holder instructed all the trades**. This is the highest-confidence multi-agent case (0.94): a stark trading anomaly plus explicit communications tying it to the POA holder.

## 2. Detection

**TM** flags the **activity spike and harm**: 47 trades vs a 2/month baseline (a ~23× anomaly) and a **22% account decline** — classic churning/exploitation signature. TM confidence **0.82**, *trading* domain (authority 0.95).

**CS** flags the **communications**: messages showing the **POA holder directing every trade**, combined with the vulnerable-client profile (age 84, POA only 6 weeks old). CS confidence **0.78**, *communications* domain (authority 0.95).

## 4. Consensus (worked)

Corroboration → Dempster-Shafer, each agent weighted in its own domain:

```
m_TM(V) = 0.95 · 0.82 = 0.779
m_CS(V) = 0.95 · 0.78 = 0.741
Belief(V) = 0.779 + 0.741 − 0.779·0.741
          = 1.520 − 0.5772 = 0.9428 ≈ 0.94
```

Consensus confidence **0.94**, severity **CRITICAL**.

## 5. Escalation

CRITICAL → severity floor **T4**; confidence 0.94 → band **T4**; **tier = max(T4, T4) = T4** (Director/CCO). SLA ack 15 m / resolve 24 h. Because a vulnerable adult is at ongoing risk, the package surfaces the **FINRA Rule 2165 temporary-hold option** on disbursements/trades and a **trusted-contact / Adult Protective Services referral** — but the hold and any referral are **human-authorised** at T4, never auto-executed.
